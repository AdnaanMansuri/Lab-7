# Screenshots

The application running against the live MySQL database (`customerdb.student`),
showing the full set of student fields and the complete CRUD flow.

| File | Screen | Shows |
|------|--------|-------|
| `01-form-empty.png` | **Form** (Create) | The registration form with every field: name, gender, **date of birth (calendar)**, auto **age**, masked **phone**, **email**, college, **experience**, hobbies, **photo**. |
| `02-form-filled.png` | **Form** (Create) | The form filled in for a new student, with a **photo** uploaded and previewed. |
| `03-add-success.png` | Create → success | The "Success!" dialog shown after inserting, including the student's photo. |
| `04-view-jtable.png` | **View** (Read) | The mandatory **`JTable`** populated from the database — note the **photo thumbnail** in Sam's row. |
| `05-view-edit.png` | **View** (Update) | A row selected and **Edit** pressed: the record is loaded into the now-enabled edit fields (incl. photo). |
| `06-view-after-delete.png` | **View** (Delete) | The table re-read from the DB after deleting a row. |
